# Mushroom Classification Using Machine Learning

## Project Overview

This project uses machine learning to classify mushrooms as edible or poisonous based on their physical characteristics.

Two classification algorithms are implemented and compared:

- **Decision Tree Classifier**
- **K-Nearest Neighbors (KNN)**

The models are evaluated using accuracy and confusion matrices.

> **Disclaimer:** This is an educational machine learning project. Its predictions must not be used to determine whether real mushrooms are safe to eat.

## Dataset

- **Source:** [UCI Machine Learning Repository — Mushroom Dataset](https://archive.ics.uci.edu/dataset/73/mushroom)
- **Dataset size:** 8,124 instances
- **Features:** 22
- **Target:** Edible or poisonous
- **Data type:** Categorical

The dataset is loaded directly in the notebook using the `ucimlrepo` package.

## Data Preparation

The notebook performs the following steps:

1. Loads the dataset and examines its structure.
2. Checks for missing values.
3. Handles missing categorical values using the most frequent value.
4. Converts categorical features into numerical representations using one-hot encoding.
5. Splits the data into 80% training and 20% testing sets.

## Models and Evaluation

Both models are trained using the same training and testing split.

Evaluation metrics:
- Accuracy
- Confusion matrix

The notebook displays the measured accuracy of each model and identifies which model performs better on the test set.

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/mushroom-classification-ml.git
cd mushroom-classification-ml
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Launch Jupyter Notebook

```bash
python -m jupyter notebook
```

Open `mushroom_classification.ipynb` and run all cells from top to bottom.

An internet connection is required to fetch the dataset.
